# CoffeeDex - Sprint Management

## Quick Reference

```
/project:status          # View project status and goals
/project:sprint-goals    # Plan sprint goals
/project:sprint-dispatch # Execute a sprint
/project:sprint-status   # Check active sprint progress
```

## Project Structure

- `.claude/project.yaml` - Project goals and focus
- `.claude/sprints/` - Sprint definitions and history
- `.claude/dispatch/` - Dispatch logs and registry
- `.claude/hooks/` - Autonomous workflow hooks
- `.claude/state/` - Runtime state files
